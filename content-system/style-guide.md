# 风格指南

> 视觉方法学自 [kinetic-reel](https://github.com/tuzhechen2005/opus-video-skills)（动效排版短片）和 [lemo-opuscar](https://github.com/lemomo-ai/lemo-opuscar) 的导演方法（DIRECTOR.md），只学语法，不照搬设计。
> 001 期做了三轮才找到方向：写实 3D 加小号界面卡片看起来像软件截图，换成**动效排版**才有冲击力。别再走回头路。

## 1. 结构

- **长度 60–90 秒**，竖屏 1080×1920，30 fps。
- **前 3 秒必须是钩子**：一个可疑的承诺、一个反常的数字或一个问题。不放片头 Logo。
- **一个主体、一个目标、一个转折**。结尾呼应开头。
- **一个招牌镜头**：只有代码动画能做到的那一下，放在情绪最高点（001 期是 MLCC 当场 X 光再拆开）。
- **先写分镜方案（TREATMENT.md），再动手做画面。**

## 2. 画面

**排版是主角。**

| 元素 | 规则 |
|---|---|
| 大标题 | Anton，一到两行，以句号结尾，自动适配宽度。给关键词或句号上强调色 |
| 重锤词 | Archivo Black，单个词，上下叠描边回声 |
| 标签、HUD、数据 | JetBrains Mono，加字距 |
| 字幕 | Inter 粗体，深色底，左侧是 AI 主播 |
| 数字 | Anton 大号，滚动或翻牌出现 |

**配色**（`pipeline/reel/engine.js` 里的 `K`）：墨黑 `#0E0F0E`、奶白 `#F1EEE6`、荧光绿 `#DDF53D`（主强调色、"通过"）、电光蓝 `#2F3CFF`、红 `#E8412F`（只给失败、警告和句号）。
**每个镜头换一种底色**，让每次切换都看得见。

**每个镜头要有一个机制**，不能只有字：缺货就让载带口袋一个个空掉，满足率就画 10 张订单只有 3 张打勾，核对就让目标框锁定字段。

**版式**（竖屏安全区）：左右边距 80；内容区 y 170–1420；字幕区 y 1450 起；y 1720 以下留给平台的标题和按钮。右侧不放关键信息（平台的点赞评论按钮在那里）。

**转场**用穿过画面元素的方式（圆形扩散、穿过某个元素放大、推镜、百叶、网格），每个 0.45–0.6 秒，不要连续三个同一种。章节重锤用硬切加冲击。

## 3. 声音

- 配乐由 `pipeline/synth.mjs` 合成，120 BPM，和画面读同一份时间表（`cues.mjs`），动作落在拍点上。
- **转场不用噪声嗖声**（听多了烦）。章节切换用反向铺底，场内用小的音高提示，大约一半的切换不加音效。
- 每个看得见的动作都有声音：字母落下的嘀嗒、标签的提示音、快门、目标框锁定、计数器滚动。
- 至少两处近乎静音，放在转折之前。
- 人声出现时配乐自动压低（渲染时侧链压缩），总响度 −14 LUFS。

## 4. 旁白

- 英文，短句，平静自信。
- 数字念成英文单词，写进字幕时用阿拉伯数字（`episode.json` 里每句可以分别写 `text` 和 `say`）。
- 缩写要拼读：MLCC → `M-L-C-C`，DDR5 → `D-D-R five`。
- 配音模型：Kokoro（本地），默认音色 `am_michael`，语速 1.08。

## 5. 事实红线

- 画面和旁白里的每个事实都要在 `FACTS.md` 里有出处，标明状态（✅ / ⚠️ / ❌）。❌ 不得出现。
- 来源只是"据报道"的，旁白里要说 *reportedly*。
- 示意内容（虚构料号、示例格式、层数示意）在画面上标 `EXAMPLE` 或 `SCHEMATIC`。
- 不出现真实品牌标志；不点名客户和你的公司。
- 片尾标注 `AI-generated voice & visuals`。

## 6. 发布前自检

- [ ] 联系表每个镜头都看过：没有文字互相压住，没有内容进入字幕区和平台遮挡区
- [ ] 每个转场抽帧看过，没有空白帧
- [ ] 字幕与配音同步
- [ ] 响度约 −14 LUFS
- [ ] FACTS.md 里没有 ❌，⚠️ 已由你确认
