# 信息源清单

每周日扫一遍。**来源等级**：A = 原始出处（原厂公告、政府文件、机构原报告）；B = 专业行业媒体；C = 分销商博客、二手转述（只能当线索，必须追到 A 或 B 才能上画面）。

## 英文

| 来源 | 看什么 | 等级 |
|---|---|---|
| TrendForce 新闻与 Market Bulletin | 存储、MLCC 价格与供需预测 | A/B |
| DIGITIMES、Nikkei Asia 半导体板块 | 产业链新闻，尤其台湾、日本、韩国厂商 | B |
| EE Times、EDN、Electronic Design | 产业与技术新闻 | B |
| SemiMedia | 元器件价格与市场简报 | B |
| ECIA（电子元器件行业协会） | 行业标准、市场调查 | A |
| 原厂新闻稿与客户通知（TI、ADI、NXP、ST、Infineon、Microchip、Murata、Samsung Electro-Mechanics、TDK、Yageo 等） | 涨价函、停产通知（PCN/EOL）、交期 | A |
| Fusion Worldwide Greensheet、Sourceability 交期报告 | 现货市场月报、交期 | C（分销商）→ 追原始数据 |
| Findchips / Octopart | 料号库存与价格信号 | C（参考） |
| USTR、CBP、美国商务部 BIS | 关税与出口管制 | A |

## 中文

| 来源 | 看什么 | 等级 |
|---|---|---|
| 商务部、海关总署公告 | 出口管制、进出口数据 | A |
| 第一财经、财新、科创板日报 | 国内厂商与市场新闻 | B |
| 国内存储与元器件厂商公告（长鑫、长江存储、风华高科、三环集团等） | 产能、新品、价格 | A |
| 华强北现货报价（商户、行情群、行情网站） | 现货价格的早期信号 | C → 需要至少两个独立来源交叉验证 |
| 你自己的工作 | 客户在问什么、哪些料缺、报价怎么变 | 一手（画面上不点名客户和公司） |
