# 给 Codex 的提示词 · 第 0 期「粉丝突破1000加油」

> 用法：在空目录里打开 Codex，把下方代码块整段粘进去。
> 分镜原稿见同目录 `ep00-fans-1000-challenge.md`。

```text
你是一名「代码做视频」工程师。请在当前目录从零搭一个可复用的竖屏短视频渲染工程，
把下面的分镜脚本渲染成一条成片 MP4。不要问我问题，遇到不确定的地方按"合理默认"处理，
并在最后的 README 里写明你做了哪些假设。

## 一、交付物
1. out/ep00.mp4：1080×1920，30fps，H.264 + AAC，总时长 28–30 秒。
2. 一条命令重渲染：`npm run render`（或 `make render`），从配音到成片全自动。
3. README.md：环境依赖、如何替换实拍素材、如何改文案后重渲染、你做的假设。
4. out/check/：每个镜头中点各抽 1 帧 PNG，供我人工检查。

## 二、技术路线（按这个来，不要换）
- 画面：HTML + CSS + GSAP 写每个镜头的动画，时间轴由一个全局 `t`（秒）驱动，
  保证确定性渲染（禁止用 Date.now / requestAnimationFrame 的真实时间）。
- 渲染：Playwright（Chromium）逐帧截图 → ffmpeg 合成。
  本机已有 Chromium 时用 executablePath，不要执行 playwright install。
- 配音：edge-tts，音色 zh-CN-YunxiNeural（年轻男声，口语感），rate 可微调。
  **配音先行**：先逐句生成音频，用 ffprobe 量出每句真实时长，再用这些时长排画面和字幕，
  不要反过来硬塞。总时长超过 30 秒就把 rate 调到 +5%～+10%，仍超就压缩镜头间留白。
- BGM / 音效：不要联网下载。音效用 ffmpeg（sine/anoisesrc 等滤镜）程序化合成占位版，
  放在 assets/sfx/，文件名语义化（ding.wav、record-scratch.wav、crash.wav……），
  方便我之后替换成真素材。BGM 同理，人声出现时自动压低（sidechain 或分段音量）。
- 字体：只用开源可商用字体（Noto Sans SC 做正文字幕，ZCOOL KuaiLe 做花字），
  放在 assets/fonts/ 本地加载；拿不到就回退系统中文字体并在 README 说明。

## 三、主角与实拍素材（重要）
主角是写实风虚构男生：20 多岁，黑框眼镜、短乱发、灰卫衣，深夜书桌、台灯、电脑、手机。
代码画不出写实真人，所以每个镜头分两层：
- 底层「人物层」：读取 footage/shot{1..6}.mp4（我之后用实拍或即梦/可灵生成后放进来，
  自动裁切/缩放到 9:16 填满，按镜头时长截取）。
- **文件不存在时**，用 SVG/Canvas 画一个扁平插画版主角兜底（黑框眼镜、乱发、灰卫衣、
  台灯暖光 + 深色背景），做出该镜头要求的关键动作（推眼镜、后仰、抬头看镜头、捂脸、笑），
  保证没有任何实拍素材也能完整渲出一条可看的预览片。
- 顶层「信息层」：手机/电脑屏幕界面、进度条、花字、字幕，全部用代码画，永远叠在最上面。

## 四、全局视觉规范
- 安全区：抖音右侧有点赞/评论按钮、底部有文案和进度条，
  字幕与花字不得进入右侧 160px、底部 380px、顶部 140px 区域（进度条除外，见下）。
- 字幕：底部安全区上沿，白字 + 黑描边，单行不超过 14 个字，超长自动断行，逐句跟配音对齐。
- 进度条（连续追更钩子）：从镜头 2 开始全程常驻于顶部安全线下方，
  样式"冲 1000 粉进度 ▱▱▱▱▱▱▱▱▱▱ 0/1000"，数值做成配置项（下期改成 3/1000 即可复用）。
- 整体调性：像真人随手记录，暖色台灯 + 深夜冷色屏幕光；轻微手持晃动（代码模拟，幅度小）。
- 手机界面只画一个通用的"个人主页"样式（头像、昵称"陈工研究 Ai"、粉丝 0、获赞 4），
  不要使用任何平台的 logo 或商标图形。

## 五、分镜（时长为目标值，以配音实测为准微调）

镜 1｜0–3s
画面：第一帧就是手机屏幕特写，个人主页"粉丝 0｜获赞 4"清晰可见；手指点"0"两下，
镜头快速拉远露出主角，推眼镜，面无表情盯手机。
旁白：0 粉丝，4 个赞。（停半拍，平淡）抖音说……让我冲一千。
花字：大字「0 粉 → 1000？」；"4 个赞"旁小字「（其中一个可能是我自己点的）」
音效：提示音"叮"；拉镜时唱片急停。
硬性要求：第 0 帧就必须能看到"0 粉丝"，这是 2 秒钩子。

镜 2｜3–7s
画面：手机扣桌，打开笔记本；屏幕特写，文档里逐字打出标题「研究课题 #001：从 0 到 1000 粉」；
切回主角，表情认真。
旁白：（叹气）行……那就当个课题研究。（小声）先问问 AI。
花字：顶部进度条首次出现 0/1000，此后常驻。
音效：键盘连击；回车"哒"。

镜 3｜7–13s
画面：电脑屏幕上 AI 回答快速向下滚动，列表"①保持日更 ②打造人设 ③真人出镜 ④蹭热点……⑱"，
滚动条越来越短；切回主角慢慢后仰；读到"真人出镜"停住，缓缓抬头看镜头。
旁白：它一口气给了我十八条。（停顿）第三条：真人出镜。（抬头，停一秒）……这算吗？
花字：「18 条建议」；"真人出镜"被黄色手绘框圈出；主角脸旁弹出「？」
音效：滚动"嗖嗖"；看镜头那一刻全部声音静音 1 秒（包括 BGM）。

镜 4｜13–17s（翻车）
画面：主角挺直腰、抬手准备网红开场；破音的同时手机支架前倒，画面黑一下、剧烈晃一下；
之后主角扶支架捂脸。
旁白：（清嗓，播音腔）家人们——（破音）……（沉默一秒）算了，这不是我。
花字：「研究翻车 ×1」；进度条红闪一下，文字临时变为「0/1000（非常稳定）」再恢复。
音效：破音（TTS 后把"家人们"末尾做升调/失真处理）；"哐当"；乌鸦叫占位音。

镜 5｜17–22s
画面：扶正支架、揉头发、坐好；文档里删掉"打造人设"一行，打出「研究结论：别演，做我会做的」；
镜头从屏幕慢推到侧脸，主角没忍住笑。
旁白：研究结论：表演，我不行。（笑）折腾，我还行。
花字：屏幕文字特写即可，不另加花字。
音效：删除键"哒哒哒"；轻快 BGM 进入。

镜 6｜22–29s
画面：主角举手机正对镜头，手指点向画面下方评论区位置；最后 2 秒定格，
进度条 0/1000 发光呼吸闪烁，下方出现指向评论区的箭头动画。
旁白：你被 AI、软件卡住的问题，扔评论区。我来研究。（停顿）我不一定会……但我会研究。
花字：大字「你出题，我研究 ↓」；底部口号「我不一定会，但我会研究」；
进度条旁小字「第 1 个关注，会是你吗？｜每期更新进度」
音效：BGM 鼓点落下；定格时"叮"收尾。

## 六、工程结构（建议）
config/ep00.json   # 所有文案、时长、进度条数值、音色参数——改文案只改这里
src/scenes/        # 每个镜头一个模块，导出 render(t, ctx)
src/overlay/       # 进度条、字幕、花字等可复用组件
scripts/tts.*      # 逐句配音 + 量时长 → 生成 timeline.json
scripts/render.*   # Playwright 逐帧截图
scripts/mux.*      # ffmpeg 合成画面 + 人声 + BGM + 音效
footage/           # 放实拍/AI 生成素材（可为空）
assets/            # 字体、音效、BGM
out/               # 成片与抽帧

## 七、自检（全部通过才算完成）
1. ffprobe 确认：1080×1920、30fps、时长 28–30 秒、有音轨。
2. 抽 out/check/ 帧，逐张检查：中文无乱码/方块字、字幕与花字不压安全区、
   第 0 帧可见"0 粉丝"、镜 6 定格帧有口号和进度条。发现问题就改代码重渲染，直到没问题。
3. footage/ 为空时也能完整跑通；放入任意一个 shotN.mp4 后重渲染，该镜头自动换成实拍。
4. 在 README 末尾列出：每句配音的实测时长、最终各镜头起止时间、你做的所有假设。
```
