# 风格实验

先不管选题和文案，只验证视觉语言。定下来的手法再写进 `content-system/style-guide.md`，用到正式的期数里。

## 为什么要单独做风格实验

001 期前三版的问题出在思路上：**旁白驱动**。先写文案，每句旁白配一个镜头，每个镜头都是"大标题 + 一张小示意图"，再用同一个模板换颜色重复十次。结果标题落下后画面就静止好几秒，像一页页翻 PPT，转场再花哨也救不回来。

案例里惊艳的片子是**画面驱动**的：
- 一个连续的世界，镜头不切换，靠变形和穿越推进，从宏观一路推到微观
- 节奏先行，十几秒里几十个动作卡在鼓点上，有快有慢有停顿，没有死画面
- 一个只有代码能做到的视觉点子撑起整片，加上大量元素同步运动
- 文字是画面里的一层，不是每个镜头的主体

## style-01-powers-of-ten（十的次方）

16 秒，无旁白，一镜到底，视野从约 4 米推到几十微米再拉回：

| 时间 | 画面 |
|---|---|
| 0–1 s | 黑场里一个荧光绿点随底鼓跳动 |
| 1–2 s | 绿点变成一卷 7 英寸料盘的轴心 |
| 2–4 s | 镜头急速拉远，整墙料盘从中心向外波浪式弹出；4,000 重锤落下 |
| 4–5 s | 俯冲进中间那卷，镜头转 180° 落到载带上 |
| 5–9 s | 底色换成荧光绿，贴着载带高速飞行；每拍一个巨字 REAL / STOCK / OR / BAIT? |
| 9–11 s | 停在一格口袋上，MLCC 升起，X 光扫过 |
| 11–13.4 s | 60 层电极像手风琴一样扇形展开 |
| 13.4–14 s | 钻进两层电极之间："look inside / BEFORE YOU PAY." |
| 14–15 s | 一秒内沿原路退出，再转身拉回整墙 |
| 15–16 s | 整墙标签从中心向外依次变绿，VERIFIED. |

左下角的 FIELD 读数是实时视野尺寸，单位从毫米变成微米。

```bash
node experiments/style-01-powers-of-ten/music.mjs
node pipeline/render.mjs experiments/style-01-powers-of-ten --out experiments/style-01-powers-of-ten/build/style-01.mp4
```
