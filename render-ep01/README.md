# 第 0 期「粉丝突破1000加油」· 代码渲染版

成片：`out/ep01.mp4`（1080×1920，30fps，约 32 秒）

形式是「录屏式」：整条视频都发生在主角的手机屏幕里，旁白用第一人称。
主页按真实账号数据重建（0 粉丝 / 4 获赞 / 2 新访客 / 粉丝突破1000 活动卡），
头像和作品封面取自主页截图（`assets/img/`）。

| 镜 | 内容 |
|---|---|
| 1 | 主页特写：圈出 0 粉丝 → 4 获赞 → 2 个新访客冒出来又溜走（数字变 0） |
| 2 | 拉远滚到活动卡，点「去发布」→ 卡片展开成「研究课题 #001：粉丝突破 0→1000」 |
| 3 | 问 AI → 18 条建议刷屏 → 荧光笔划出「真人出镜」→ 静音一拍推近 |
| 4 | 前置相机 3-2-1 开录 →「家人们」破音 → 画面撕裂、摔机 →「录制已中断：检测到播音腔」 |
| 5 | 实验报告：表演能力 9%，折腾能力 97%（样本量：1） |
| 6 | 你出题，我研究（评论区点单示例轮播）→ 结尾卡：口号 + 0/1000 + 关注 |

## 重渲染

```bash
npm install
pip install edge-tts numpy scipy
npm run render     # 配音 → 触发点 → 混音 → 逐帧渲染 → 自检抽帧
```

- 改文案/节奏：只改 `config/ep01.json`，配音先行，画面按实测时长自动对齐。
- 下期改进度：改 `config/ep01.json` 里的 `progress.current`。
- 音效都是程序合成的占位版，在 `assets/sfx/`，同名替换成真素材即可（删掉文件会重新合成）。
